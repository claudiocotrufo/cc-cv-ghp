Where I have worked

MSC

Tech Lead, Frontend Jul 2022–present

Mediterranean Shipping Company, Turin. Frontend tech lead on the msc.com corporate websites, built as headless Angular 17 front ends on the Sitecore 10 CMS and hosted on Microsoft Azure.

  • Set the technical direction for the move from an ASP.NET MVC monolith to headless Angular 17, laying the foundations of the projects now in production.
  • Started an Angular 22 rewrite to break up the legacy monolith and lighten deployments, while the team evaluates Storyblok.
  • Covered every project in a team of 4 developers in Turin and 6 in Chennai, running sprint planning, estimates and stakeholder meetings.
  • Supervised the fortnightly releases on Azure DevOps, reviewing the code before each one ships.
  • Ported Alpine.js mock-ups into Razor views on ASP.NET, the double work the Angular move removed.
  • Mentored the junior developers and ran technical interviews for 4–5 candidates, feeding back on the team to the line manager.
